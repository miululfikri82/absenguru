Pengaturan & data gaji bisa disimpan/dimuat dari Google Spreadsheet milik Anda sendiri. Layanan ini gratis, tidak butuh kartu kredit — Anda hanya perlu membuat "OAuth Client ID" sendiri lewat akun Google (gratis, sekali setup).
Cara membuat OAuth Client ID (gratis, ± 5 menit)
  1. Buka console.cloud.google.com, buat project baru (gratis).
  2. Buka menu APIs & Services → Library, cari Google Sheets API, klik Enable.
  3. Buka APIs & Services → OAuth consent screen, pilih tipe External, isi nama app & email, simpan (biarkan status "Testing").
  4. Di bagian Test users, tambahkan alamat Gmail yang akan dipakai untuk login ke aplikasi ini.
  5. Buka APIs & Services → Credentials → Create Credentials → OAuth client ID, pilih tipe Web application.
  6. Di Authorized JavaScript origins, tambahkan alamat tempat file HTML ini dibuka (mis. http://localhost kalau dibuka langsung dari komputer, atau domain hosting Anda).
  7. Klik Create, salin Client ID yang muncul, tempel di kolom di bawah ini.
  8. Buat Google Spreadsheet kosong, salin ID-nya dari URL (bagian di antara /d/ dan /edit), tempel di kolom Spreadsheet ID.
Belum terhubung ke Google.
